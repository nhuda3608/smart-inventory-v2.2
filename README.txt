GitHub এ সাব-ফোল্ডার ছাড়া আপলোড করার জন্য - সব ফাইল একটি ফোল্ডারে
================================================================

এই ফোল্ডারে সব ফাইল FLAT আছে - কোন সাব-ফোল্ডার নেই।
GitHub ওয়েবে "Add file -> Upload files" এ সব ফাইল একসাথে Drag & Drop করুন।

কী কী আছে (22টি ফাইল):
- 7টি .kt ফাইল (Login, OTP, Dashboard, Sale, Stock, Income, Ledger)
- 3টি .xml layout
- AndroidManifest.xml, app_build.gradle, root_build.gradle, settings.gradle
- gradle-wrapper.jar, gradle-wrapper.properties, gradlew
- strings.xml, colors.xml
- 2টি Zip (ব্যাকআপ)
- .github/workflows/build.yml (স্পেশাল - Flat ফাইলগুলো অটো সাজিয়ে APK বানাবে)

GitHub এ আপলোড করার পর Workflow অটো ফোল্ডার স্ট্রাকচার বানিয়ে APK তৈরি করবে।

যদি GitHub ডেস্কটপে ফোল্ডার আপলোড করতে পারেন, তবে SmartInventoryApp_ReadyToBuild.zip
আনজিপ করে পুরো SmartInventoryApp ফোল্ডার আপলোড করাই ভালো।
